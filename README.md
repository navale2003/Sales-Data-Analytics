# Sales-Data-Analytics

## Project Overview

This project analyzes e-commerce sales data to identify revenue trends, profitability, customer behavior, and payment-method patterns.

## Objectives

* Analyze sales and revenue performance.
* Evaluate profit and profit margins.
* Explore customer and state-wise performance.
* Identify sales trends over time.
* Present business insights using an interactive Power BI dashboard.

## Tools and Technologies

* Python
* SQL
* Power BI
* Pandas
* Data cleaning and exploratory data analysis

## Project Structure

* `sql/` — SQL queries and analysis
* `README.md` — Project documentation
* `ecommerce.db` — SQLite database, if appropriate to share
* Power BI dashboard and Python analysis files — as included in the project
